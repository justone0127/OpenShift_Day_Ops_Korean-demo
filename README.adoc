= OpenShift Ops Day Roadshow

Showroom content for the OpenShift Ops Day Roadshow, covering Day 2 operations for OpenShift administrators.

== Workshop Overview

A comprehensive modular workshop for OpenShift administrators. Modules are selectable at catalog order time so instructors can tailor the content to their audience.

=== Available Modules

*Getting Started*

* *link:content/modules/ROOT/pages/index.adoc[Setup & Overview]* (15-20 min) - Lab access, Showroom interface, CLI verification, platform overview, console, monitoring, registry, routing, upgrades, operator ecosystem
* *link:content/modules/ROOT/pages/01-installation.adoc[01 - Installation & Verification]* (10 min) - ClusterOperator health, node status, etcd metrics, storage provisioning, update channels

*Core Operations*

* *link:content/modules/ROOT/pages/02-app-mgmt.adoc[02 - Application Management]* (15-20 min) - Deployment, Routes with TLS, scaling, self-healing, probes, rollback, PodDisruptionBudgets
* *link:content/modules/ROOT/pages/03-ingress-loadbalancing.adoc[03 - Ingress & Load Balancing]* (25 min) - Ingress Controller, Routes with TLS termination, rate limiting, IP allowlist, Services
* *link:content/modules/ROOT/pages/04-network-security.adoc[04 - Network Security]* (10-15 min) - OVN-Kubernetes, NetworkPolicy, AdminNetworkPolicy, EgressFirewall, EgressIP
* *link:content/modules/ROOT/pages/05-debugging-troubleshooting.adoc[05 - Debugging & Troubleshooting]* (10-15 min) - Diagnostic toolkit, fixing ImagePullBackOff, CrashLoopBackOff, resource constraints, SCC permissions
* *link:content/modules/ROOT/pages/06-gitops.adoc[06 - OpenShift GitOps]* (10-15 min) - ArgoCD, app deployment from Git, drift detection, self-healing

*Identity & Access*

* *link:content/modules/ROOT/pages/07-ldap-authentication.adoc[07 - LDAP Authentication]* (15-20 min) - OAuth configuration, LDAP structure, group sync, RBAC
* *link:content/modules/ROOT/pages/08-oidc-authentication.adoc[08 - OIDC Authentication]* (15-20 min) - Red Hat build of Keycloak deployment, OIDC configuration, group sync, RBAC

*Day 2 Operations*

* *link:content/modules/ROOT/pages/09-observability.adoc[09 - Observability & Logging]* (35-40 min) - Prometheus metrics, dashboards, user workload monitoring, Alertmanager, OpenTelemetry distributed tracing, logging stack
* *link:content/modules/ROOT/pages/10-performance-tuning.adoc[10 - Performance Tuning]* (15-20 min) - Resource diagnostics, VPA right-sizing, HPA autoscaling, performance monitoring

*Advanced Topics*

* *link:content/modules/ROOT/pages/11-virtualization.adoc[11 - Virtualization]* (20-25 min) - VM creation, networking, live migration, cloning, snapshots
* *link:content/modules/ROOT/pages/12-developer-hub.adoc[12 - Developer Hub]* (25-30 min) - Software catalog, Topology plugin, software templates, platform architecture
* *link:content/modules/ROOT/pages/13-openshift-lightspeed.adoc[13 - OpenShift Lightspeed]* (15-20 min) - AI assistant, OLSConfig creation, console integration
* *link:content/modules/ROOT/pages/14-acm.adoc[14 - ACM Multi-Cluster Management]* (30 min) - ACM, hosted control planes, VM management, GitOps app deployment, policy-based governance
*Security Track (누리페이 침해사고 시나리오)*

== Module Selection

Modules are selectable at catalog order time. The navigation dynamically shows/hides content based on which modules are enabled.

Catalog parameters (`module_enable_*`) control both:

* Which operators/workloads get deployed
* Which content appears in the workshop navigation

See link:content/modules/ROOT/nav.adoc[nav.adoc] for the conditional navigation logic using `ifeval`.

== Local Development

=== Using local-build scripts (Recommended)

From the repo root, build and preview the workshop with Podman:

[source,sh]
----
./local-build/up.sh
----

Open http://localhost:8080/index.html in your browser.

Other commands:

[cols="1,2"]
|===
| `./local-build/build.sh` | Generate the static site into `./www/` using `site.yml`
| `./local-build/serve.sh` | Serve `./www/` with httpd in Podman (port 8080)
| `./local-build/stop.sh` | Stop the local httpd container
| `./local-build/reset.sh` | Stop, rebuild, and serve again
| `./local-build/status.sh` | Show container status
|===

Optional environment variables (see `local-build/_common.sh`):

* `SHOWROOM_PORT` — host port (default `8080`)
* `SHOWROOM_PULL=1` — pull the httpd image before starting
* `SHOWROOM_SITE_YML` — alternate Antora playbook (default `site.yml`)

=== Using Antora CLI directly

[source,sh]
----
npm i -g @antora/cli@3.1 @antora/site-generator@3.1
antora generate site.yml --stacktrace
----

Output is generated in `./www/`. Serve with `./local-build/serve.sh` or any static file server.
